# Energy-consumption-forecasting
Forecasting hourly electricity consumption using time-series analysis and machine learning models.

#Project Title: Energy Consumption Forecasting Using Machine Learning (ML)

#About Dataset: PJM Hourly Energy Consumption Data, available through the Kaggle Hourly Energy Consumption dataset.

PJM Interconnection LLC (PJM) is a regional transmission organization (RTO) in the United States. It is part of the Eastern Interconnection grid, operating an electric transmission system serving all or parts of Delaware, Illinois, Indiana, Kentucky, Maryland, Michigan, New Jersey, North Carolina, Ohio, Pennsylvania, Tennessee, Virginia, West Virginia, and the District of Columbia.
The hourly power consumption data comes from PJM's website and is in megawatts (MW).
The regions have changed over the years, so data may only appear for certain dates per region.

This project forecasts hourly electricity consumption using historical energy demand data and machine learning techniques. Accurate electricity demand forecasting is important for power system operation, energy management, and resource planning.

#Objectives

Analyze historical electricity consumption patterns.

Identify trends, seasonality, and daily/weekly demand variations.

Develop and compare statistical and machine learning forecasting models.

Evaluate forecasting accuracy using MAE and RMSE.

Visualize actual versus predicted electricity demand.

#Planned Methods

Exploratory Data Analysis (EDA)

Feature Engineering

Seasonal Naive Forecasting

Linear Regression

Random Forest Regression

XGBoost (future extension)
